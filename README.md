## Hands-on Learning

I learn best by taking a design from specification to simulation and implementation.

A typical workflow I follow:

1. Understand the interface and expected behaviour.
2. Design the RTL architecture and split it into modules.
3. Write a testbench with meaningful stimulus.
4. Check normal operation, boundaries, corner cases and timing.
5. Inspect waveforms and debug mismatches.
6. Run synthesis or FPGA implementation when the target hardware is available.
